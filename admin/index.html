Not built yet, and why

An honest list, so nothing here looks finished when it is not.

Blocking an account

Needs a database change first. There is no "blocked" mark today, and adding one is only half the job: every rule that lets somebody write something has to check it, or a blocked person carries on exactly as before. That is a migration, not a page.

Deleting an account and its data

Cannot be done from a browser at all, by design. Removing a sign-in needs a key that must never leave a server. It has to be a small server function, like the one that already sends notices, which checks you are an admin and then does the deletion itself.

Reported events and comments

Reports are stored but not shown here yet. The app has its own screen for them.

Sending a notice as a phone notification

Writing and editing notices works here. Actually pushing one to phones still goes through the app, which calls the server function that holds the Firebase credentials.
